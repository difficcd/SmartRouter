# v17 — 마커 단어 확장 (기각) + 방법론 정정 두 건

브랜치: `SmartRouter-v17` (base: `main` @ v16)

## 배경

오라클 분해상 개선 여지의 96%가 점수 예측 쪽에 있고, 점수 예측 계열에서
유일하게 성공한 전례가 v8의 마커 단어 확장이었다. 그래서 여기를 더 팠다.

동시에 v8에는 검증 구멍이 있었다 — v12 이전이라 **Dev로만 검증**했고 Train에서의
효과는 확인된 적이 없었다.

## 정정 1 — 첫 ablation 수치는 confound였다 (내 실수)

처음에 "v8 단어 목록을 빼면 Dev -0.0095 / Train -0.0104"라고 보고했다. **틀렸다.**

`train_router.py`의 `--cost-fit` 기본값이 `split`인데 `main`은 `classic`(Duan
smearing)으로 구워져 있다. 재학습할 때 인자를 안 줘서 **비용 모델 계열 자체가
바뀌었고**, 그 효과가 단어 목록 효과를 완전히 덮었다.

얼마나 큰 차이였냐면:

| 모델 | dev 예측 light 총합 / 실제 |
|---|---|
| classic (main) | 5.5 / 4.4 = **1.258** |
| split | 4.5 / 4.4 = 1.024 |

cap은 **예측** light 총합에 곱해지므로, 같은 `safety_ratio`가 두 모델에서
전혀 다른 실제 예산을 뜻한다. 그래서 승격 건수가 fast 30건 -> 12건으로 줄었다.

`--cost-fit classic`을 맞춰 다시 재면 **v8 목록의 실제 기여는
+0.00068 Dev / +0.00119 Train**이다. v8이 원래 보고한 +0.00034와 같은 규모다.

교훈: **한 번에 한 가지만 바꾼다.** 그리고 재학습 시 `main`이 어떤 플래그로
구워졌는지부터 확인한다. (파이프라인 자체는 건전하다 — 같은 플래그로 돌리면
main의 0.670341 / 0.659148을 정확히 재현한다.)

## 정정 2 — t통계량으로 순위를 매기면 안 된다

`mine_marker_words.py`를 새로 만들면서 선택 편향을 막으려고 유의성 검정을
넣었는데, **순위 기준으로 썼더니 역효과**였다.

t = 평균/표준오차이고 표준오차는 빈도에 반비례하므로, **t는 효과 크기가 아니라
빈도를 보상한다.** 그 결과 상위가 전부 불용어(`a, the, is, of, in`)로 채워졌고,
카운트 평균이 141까지 올라가 사실상 단어 수 세기가 됐다. 릿지는 이걸
`word_count_log1p`와 중복으로 보고 계수를 0 근처로 눌렀다.

**유의성은 게이트로, 순위는 효과 크기로.** 여기에 빈도 상한(`--max-df`)까지
걸어야 한다. v8이 잘 됐던 이유가 정확히 이 구조였다.

## 마커 단어의 "적정 구간"

계수를 보면 이 특징에 최적 빈도대가 있다:

| 목록 | 평균 카운트 | axk1-light 계수차 (라우팅을 바꾸는 값) |
|---|---|---|
| baseline 12개 | 0.239 | -0.0029 (사실상 0, 부호도 반대) |
| **v8 (37개)** | **1.343** | **+0.0635** |
| 통합 47개 | 16.07 | +0.0120 |
| v8 + 희귀 9개 | 2.419 | +0.0601 |

너무 드물면 거의 항상 0이라 변동이 없어 릿지가 무시하고, 너무 흔하면 길이
특징과 중복이라 눌린다. v8은 프롬프트당 1.3회로 그 사이에 있다.

## 시도한 것과 결과 (전부 `--cost-fit classic`, v16 안전 파라미터)

| 시도 | Dev | Train | premium train 예산비율 |
|---|---|---|---|
| **v16 (v8 목록) = main** | **0.670341** | **0.659148** | 2.8133 |
| baseline 12단어 (ablation) | 0.669659 | 0.657955 | -- |
| 모델별 분리 + 불용어 특징 | (confound, 무효) | | |
| 통합 47단어 | 0.669659 | 0.657955 | 3.6042 |
| v8 + 희귀 고효과 9단어 | 0.669659 | 0.658381 | 3.2077 |

셋 다 v16에 못 미치고, **premium 예산 여유가 계속 무너진다**(2.81 -> 3.21 -> 3.60).
한도가 4.0이므로 3.60은 여유 11%로 위험한 수준이다.

## 부수적으로 확인한 것 — ax31에는 고유 어휘가 없다

모델별로 따로 채굴했더니, 유의성 게이트를 통과한 **ax31 우위 단어가
`blue`, `then`, `what` 셋뿐**이었다(axk1은 55개). 이건 예전에 측정한
"ax31 승격 이득의 예측 상관 -0.05"에 대한 독립적인 확증이다. 표면 어휘로는
ax31을 골라낼 수 없다.

## 판정

**기각.** v8 목록 유지, `main`은 v16 그대로.

마커 단어 레버는 사실상 소진됐다고 본다. v8이 국소 최적점이고, 세 방향의
확장이 모두 조금씩 나빴다. 남는 산출물은 `mine_marker_words.py`(효과 크기 순위 +
유의성 게이트 + 빈도 상한)와 위 두 건의 방법론 정정이다.
