# v6 — risk_multiplier 그리드 범위 확장

브랜치: `SmartRouter-v6` (base: `SmartRouter-v3`)

## 배경

v3의 등급별 독립 탐색 결과를 보니 balanced가 `risk[ax31]=2.00`을 골랐는데
이게 `RISK_MID_GRID=[1.0,1.2,1.5,2.0]`의 **최댓값과 정확히 일치**했다 —
그리드 경계에 최적값이 있다는 건 그리드 밖에 더 나은 값이 있을 수 있다는
신호. v4·v5(모델 자체를 정교화하는 시도)가 연달아 역효과였던 것과 달리,
이건 v2·v3와 같은 "탐색 구조 개선" 계열이라 우선순위를 높여 먼저 시도.

## 변경

```
RISK_HIGH_GRID: [1.0, 1.5, 2.0, 2.5, 3.0, 4.0] → [..., 5.0, 6.0]
RISK_MID_GRID:  [1.0, 1.2, 1.5, 2.0] → [..., 2.5, 3.0]
```

model_router/train_router.py는 v3 그대로(smearing, bagging·차등정규화 없음).

## 결론

**"모델을 정교화" 대신 "이미 있는 탐색 구조의 범위를 넓히는" 접근이 다시
통했다.** fast의 `risk[axk1-think]`가 새 그리드의 최댓값(6.0)에 또 걸려서,
시간이 더 있으면 이 방향으로 한 번 더(예: 8.0, 10.0까지) 확장해볼 여지가
남아있음 — 지금은 시간 우선순위상 여기서 병합.
